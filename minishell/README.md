## Узгодження з частиною Назара (pipeline/)

Дві утиліти не мають програмних залежностей між собою.
Спільне демо:

```bash
./minishell                          # запускає REPL
$ ls -la                             # одинична команда → fork + execvp
$ ./pipeline "ls | wc -l"            # виклик зовнішньої утиліти-конвеєра
$ exit
```

Дивись також `docs/SPEC.md` у корені репозиторію — спільну специфікацію.
